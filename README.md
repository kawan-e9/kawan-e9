# kawan-e9

**Kawan E9 : Solusi di Setiap Situasi** — Direktori mandiri dan panduan praktis untuk pekerja migran Indonesia (E-9) di Korea Selatan.

## Fitur Utama
- **62 Alamat Nodongbu (고용복지+센터)** lengkap dengan alamat jalan Korea, lokasi loket, nomor telepon, dan tautan KakaoMap / Naver Map.
- **18 Alamat Shelter & Pusat Bantuan Pekerja Asing** di seluruh Korea Selatan.
- **45 Alamat Masjid & Komunitas Muslim** lengkap dengan filter provinsi & kota.
- **Simulasi Pesangon (퇴직금), Lembur & Konverter Kurs KRW → IDR**.
- **Kamus Bahasa Korea Praktis** untuk keperluan Nodongbu, pabrik, rumah sakit/Sanjae, dan sehari-hari.
- **Mode Aplikasi Standalone (PWA)** dengan tombol khusus **Full Screen**.

*Catatan: Portal referensi mandiri non-resmi · 100% gratis & non-komersial.*
